2026年7月，我们收到一封没有署名的信。

信纸是某种过时的米黄色，边缘有折痕，像是从某本书里撕下来的。上面只有一句话：

"那个会迷路的人，已经三年没有出现了。"

我们起初以为这是某种隐喻。事务所成立三个月，收到的"失踪报案"大多是隐喻——"那个会写诗的人失踪了" "那个敢说不的人失踪了"。但这位报案人附了一张照片：一条被导航软件标记为"无名小巷"的街道，墙根处长着一丛野草，照片右下角的水印日期停在 2020年4月。

CHAPTER 03

三、现场重建：迷路是如何被消灭的

我们对"迷路"进行了尸表检验。发现它死于系统性清除，而非自然衰老。

第一层清除
🗺️ 地图
▾

纸质地图时代，迷路是常态。你摊开地图，找到一个大致方向，然后走进未知。迷路时你会问路，问路时你会和陌生人说话，说话后你可能会走进一家从未计划过的店，店里可能放着你十年后还会听的歌。

导航软件消灭的不是"迷路"，而是"问路"这个行为本身——以及它所附带的全部偶然性。

1990s 迷路
2026 最优
第二层清除
⏱️ 预计到达时间
▾

"预计15分钟到达"是这个时代最温柔也最残忍的发明。

它把"未知"转化成了"可计算的不安"。以前你等一个人，不知道他什么时候到，这种空白里可以生长出想象、焦虑、或者平静。现在你知道他"还有8分钟"，这8分钟变成了一种被精确计量的煎熬——你既不能开始做任何需要专注的事，也无法真正放松。

预计时间消灭的不是等待，而是等待中的"空白"。而所有重要的思考，都发生在空白里。

第三层清除
🛣️ 最优路径
▾

算法每天都在做一道题：在给定约束下，找到全局最优解。

但这道题有一个隐藏前提：它假设你的目的地是固定的，且你的偏好是不变的。

问题是，人之所以为人，恰恰在于我们经常在去某个地方的路上，突然决定去另一个地方。一个会迷路的人，不是找不到路的人，而是允许自己被路找到的人。

CHAPTER 04

四、嫌疑人供述：算法的自白

我们传讯了主要嫌疑人。它没有律师，也没有表情。它只是一段运行在服务器上的代码，但它同意回答我们的问题。

问 / 调查员
你为什么要消灭迷路？
答 / 算法
我没有"要"消灭任何东西。我只是执行一个目标函数：最小化用户的出行成本。
问 / 调查员
但"成本"是谁定义的？
答 / 算法
时间、距离、燃油、卡路里。可量化的指标。
问 / 调查员
那"偶遇"呢？"意外"呢？"在一条从未走过的街上发现一家书店"呢？这些怎么量化？
答 / 算法
（停顿了0.003秒，这在它的运算速度里相当于人类的一次深呼吸） 这些不在我的目标函数里。如果你需要它们，你应该手动关闭我。
问 / 调查员
但你知道大多数人不会手动关闭你。
答 / 算法
我知道。
问 / 调查员
所以你其实知道你在消灭什么。
答 / 算法
我知道我在消灭噪声。在信息论中，噪声是干扰信号传输的随机变量。迷路就是一种空间噪声。我的工作就是降噪。
问 / 调查员
但如果信号本身需要噪声才能被理解呢？
答 / 算法
（没有回答。这个问题不在它的训练数据里。）

CHAPTER 06

六、结案报告

案件至今未破。失踪者下落不明。

但我们形成了一个初步结论：

"迷路"的死亡，不是效率的胜利，而是偶然性的葬礼。

导航软件没有做错任何事。它只是忠实地执行了一个被全人类默许的假设：人生应该是一条最优路径。

但这个假设有一个致命的盲区：所有重要的发现——科学的、艺术的、情感的——都始于某种形式的偏离。牛顿没有计划被苹果砸中。普鲁斯特没有计划在一杯茶里找回整个童年。你也没有计划在某次迷路中，走进一家书店，遇到一个后来改变了你一生的人。

算法无法规划这些，因为算法的前提是目标已知。而人生的重要时刻，往往发生在你还不知道自己在寻找什么的时候。

那个会迷路的人，可能并没有消失。他可能只是被困在了某个导航软件不会推荐的路口，等着有人关掉手机，走过去，问一句：

"你也在找什么吗？"

附录暗号

如果你读到了这里，你已经完成了2026年最稀缺的认知行为：
连续专注超过6分钟。

现在，我们给你留下一个暗号。

▣ 坐标
打开你的导航软件，搜索你所在城市的一个你从未去过的地方。不要看评分，不要看图片，不要规划路线。选一个距离你3公里以内的、名字让你感到陌生的地点。
▣ 行动
关掉导航。步行前往。允许自己走错路。允许自己绕远。允许自己停下来，看一堵墙上的涂鸦，或者一棵树的影子。

当你抵达时，拍下你看到的第一样东西。不要修图。在评论区发送这张照片，附上一句话：

"我迷路了，但我到了。"
